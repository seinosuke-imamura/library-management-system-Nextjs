# 図書管理システム（Next.js 版）

Hono + React(Vite) で構築した図書管理システムを、フルスタック Next.js（App Router + Route Handlers）で再実装する学習プロジェクト。

## 技術スタック（予定）

| カテゴリ | 技術 |
|----------|------|
| フレームワーク | Next.js（App Router） |
| 言語 | TypeScript |
| ORM | Drizzle ORM |
| データベース | SQLite |
| バリデーション | Zod |
| 認証 | JWT + HttpOnly Cookie |
| スタイリング | Tailwind CSS |
